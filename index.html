DETRÁS DE CÁMARA

Cómo se filmó este año

El rodaje no fue en orden. Fue ensayo, error, commit y otra vez. Estas son las cuatro escenas que más me marcaron.

  1. 01

    Primer acto

    Lógica y fundamentos

    Variables, condicionales, ciclos, funciones y los primeros scripts en Python. Aquí aprendí que un error no es el final, es una pista.

    Python · PSeInt · VS Code
  2. 02

    Segundo acto

    Datos y documentación

    Modelos entidad-relación, consultas SQL, manuales y ERS. Entendí que un sistema sin documentación es una película sin guion.

    SQL Server · SSMS · Word · draw.io
  3. 03

    Tercer acto

    Apps, juegos y pantallas

    .NET MAUI, XAML, SQLite y videojuegos. La primera vez que una app corrió en el emulador sentí que había dirigido algo de verdad.

    C# · .NET MAUI · XAML · SQLite
  4. 04

    Final

    Feria y proyecto innovador

    SignVoice AI, Etiqueta Clara y Golden Rose: presentar, defender, explicar y escuchar. El año cerró con la idea convertida en producto.

    Git · GitHub · Power BI · IA
